# RegionBrainAge

RegionBrainAge is a deep-learning model for estimating global and regional brain age from T1-weighted MRI. The released model uses a 3D DenseNet121 backbone with atlas-guided multiscale ROI pooling and provides global predictions together with age estimates for 222 brain regions.

The 222 regions comprise 200 cortical parcels from the Schaefer atlas, 15 subcortical regions from the Harvard–Oxford atlas and 7 cerebellar networks from the Buckner atlas. The trained model, composite atlas, MNI152 template and ROI lookup table are included in this repository; no additional atlas download is required.

> **Important:** The regional outputs are ROI-conditioned chronological-age estimates generated by the model. They are not direct measurements of regional biological age. RegionBrainAge is intended for research use only.

## Requirements

RegionBrainAge requires Python 3.12 and accepts T1-weighted images in NIfTI format (`.nii` or `.nii.gz`).

Create and activate the Conda environment, then install the Python dependencies with:

```bash
conda env create -f environment.yml
conda activate regionbrainage

python -m pip install -r requirements.txt
python -m pip check
```

The prediction script automatically uses a CUDA GPU when one is available and otherwise runs on the CPU.

Prediction from raw images additionally requires:

- [FSL 6.0.7.22](https://fsl.fmrib.ox.ac.uk/fsl/docs/) for image reorientation, affine registration and visual quality-control images;
- [FreeSurfer 7.4.1 (SynthStrip)](https://surfer.nmr.mgh.harvard.edu/fswiki/DownloadAndInstall) for brain extraction.

These are the versions used and recommended for reproducibility, other recent versions may be compatible. These external programs are not required for images that have already been preprocessed.

## Usage

[`predict.py`](predict.py) accepts either a single T1-weighted NIfTI image or a folder. Folder inputs are searched recursively and should contain only the intended T1-weighted images. The output directory must be new or empty.

### Preprocessed images

Preprocessed inputs must be brain extracted, have zero-valued background voxels and match the exact MNI152 1-mm grid and affine used by the model (`182 × 218 × 182` voxels). Intensity normalization is performed automatically during prediction.

```bash
python predict.py \
  --input /path/to/image_or_folder \
  --input-type preprocessed \
  --output-dir /path/to/results
```

### Raw images

Raw mode performs image reorientation, SynthStrip brain extraction and 12-degree-of-freedom affine registration to the bundled MNI152 template.

```bash
python predict.py \
  --input /path/to/image_or_folder \
  --input-type raw \
  --output-dir /path/to/results
```

Raw preprocessing also generates HTML/PNG slice views. Please inspect these images to confirm brain-extraction and registration quality before using the predictions.

## Outputs

The output directory contains:

- `predictions.csv`: global brain-age predictions;
- `regional_predictions.csv`: one row per successfully processed image, with regional age columns `roi_001` through `roi_222`;
- `roi_lookup.csv`: the mapping from each regional prediction column to its ROI identifier, atlas source and region name;
- `run_metadata.json`: model and prediction-run information;
- `failures.csv`: images that could not be processed, when applicable;
- `preprocessing_summary.csv` and `preprocessed/`: preprocessing results and quality-control images produced in raw mode.

The primary global prediction is `global_age_direct`. Regional prediction columns contain ROI-conditioned age estimates in years; a blank value indicates that the ROI was not valid for that image. A secondary ROI-aggregated global estimate is also included as `global_age_roi`.

Chronological age is not required for prediction. If a brain predicted age difference (brain-PAD) is needed, calculate it downstream as predicted age minus chronological age.
