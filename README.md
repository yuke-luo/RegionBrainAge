# RegionBrainAge

RegionBrainAge is a deep-learning model for estimating global and regional brain age from T1-weighted MRI. The released model uses a 3D DenseNet121 backbone with atlas-guided multiscale ROI pooling and provides global predictions together with age estimates for 222 brain regions.

The 222 regions comprise 200 cortical parcels from the Schaefer atlas, 15 subcortical regions from the Harvard–Oxford atlas and 7 cerebellar networks from the Buckner atlas. The trained model, composite atlas, MNI152 template and ROI lookup table are included in this repository; no additional atlas download is required.

> **Important:** The regional outputs are ROI-conditioned chronological-age estimates generated by the model. They are not direct measurements of regional biological age. RegionBrainAge is intended for research use only.

**Prediction is raw by default.** `predict.py` estimates brain age without chronological age and does not apply age-bias correction. The separate, optional [`correct_age.py`](correct_age.py) command applies frozen validation-fitted correction coefficients after prediction. It requires chronological age at MRI and produces separate corrected ages and brain-PAD values.

## Requirements

RegionBrainAge requires Python 3.12 and accepts T1-weighted images in NIfTI format (`.nii` or `.nii.gz`).

Create and activate the Conda environment, then install the Python dependencies with:

```bash
conda env create -f environment.yml
conda activate regionbrainage

python -m pip install -r requirements.txt
python -m pip check
```

The prediction script automatically uses a CUDA GPU when one is available and otherwise runs on the CPU.

Prediction from raw images additionally requires:

- [FSL 6.0.7.22](https://fsl.fmrib.ox.ac.uk/fsl/docs/) for image reorientation, affine registration and visual quality-control images;
- [FreeSurfer 7.4.1 (SynthStrip)](https://surfer.nmr.mgh.harvard.edu/fswiki/DownloadAndInstall) for brain extraction.

These are the versions used for reproducibility; other versions have not been verified here. These external programs are not required for images that have already been preprocessed. The correction script uses only the Python standard library and requires neither MRI files nor a GPU.

## Usage

[`predict.py`](predict.py) accepts either a single T1-weighted NIfTI image or a folder. Folder inputs are searched recursively and should contain only the intended T1-weighted images. The output directory must be new or empty.

### Preprocessed images

Preprocessed inputs must be brain extracted, have zero-valued background voxels and match the exact MNI152 1-mm grid and affine used by the model (`182 × 218 × 182` voxels). Intensity normalization is performed automatically during prediction.

```bash
python predict.py \
  --input /path/to/image_or_folder \
  --input-type preprocessed \
  --output-dir /path/to/results
```

### Raw images

Raw **input** mode performs image reorientation, SynthStrip brain extraction and 12-degree-of-freedom affine registration to the bundled MNI152 template. Both input modes produce raw, uncorrected brain-age estimates.

```bash
python predict.py \
  --input /path/to/image_or_folder \
  --input-type raw \
  --output-dir /path/to/results
```

Raw preprocessing also generates HTML/PNG slice views. Please inspect these images to confirm brain-extraction and registration quality before using the predictions.

## Raw prediction outputs

The output directory contains:

- `predictions.csv`: global brain-age predictions;
- `regional_predictions.csv`: one row per successfully processed image, with regional age columns `roi_001` through `roi_222`;
- `roi_lookup.csv`: the mapping from each regional prediction column to its ROI identifier, atlas source and region name;
- `run_metadata.json`: model and prediction-run information;
- `failures.csv`: images that could not be processed, when applicable;
- `preprocessing_summary.csv` and `preprocessed/`: preprocessing results and quality-control images produced in raw mode.

The primary global prediction is `global_age_direct`. Regional prediction columns contain ROI-conditioned age estimates in years; a blank value indicates that the ROI was not valid for that image. A secondary ROI-aggregated global estimate is also included as `global_age_roi`; this comes from learned attention pooling of ROI tokens and is not an arithmetic mean of regional age predictions. All three types of output are uncorrected. New run metadata explicitly records `prediction_scale: "raw"` and `age_bias_correction_applied: false`.

Chronological age is not required for prediction. If a brain predicted age difference (brain-PAD) is needed, calculate it downstream as predicted age minus chronological age.

## Optional age-bias correction

### 1. Prepare chronological ages

Create a UTF-8 CSV with the columns `subject_id,age`. Use the exact subject IDs from `predictions.csv` and chronological age **at MRI**, in years (fractional years are supported):

```csv
subject_id,age
sub-001,52.5
sub-002,68.0
```

Each successfully predicted subject must have exactly one finite, positive age. IDs are matched as text, so leading zeros are preserved; row order does not matter. Duplicate IDs or missing ages are errors. Extra age records, such as subjects whose MRI prediction failed, are ignored and recorded in the correction metadata. Ages outside the validation range of **18.75–89 years** produce an extrapolation warning and are recorded without clipping.

### 2. Apply the frozen correction

```bash
python correct_age.py \
  --predictions-dir /path/to/results \
  --ages /path/to/ages.csv \
  --output-dir /path/to/corrected_results
```

Keep `predictions.csv`, `regional_predictions.csv` and `run_metadata.json` together in the prediction directory. The correction command verifies the model checksum, coefficient checksum, ROI coverage and subject/run identities. It accepts previous raw outputs from the same bundled model even when their metadata predates the explicit raw-scale marker. The output directory must be new or empty and separate from the prediction directory. Original files are preserved; corrected outputs cannot be passed back into the command for a second correction.

### Correction method and provenance

The released model is DenseNet-121 with ROI-global auxiliary-loss weight 0.10, seed 42 and retained checkpoint at epoch 44 (selected within the run by validation total loss). The calibration contains **224 separate regressions** fitted in the **636-participant healthy validation sample**: one for each global output and one for each of the 222 regional outputs. No coefficients are fitted or updated in the new sample.

For each output, let `A` be chronological age and `P` the raw predicted age:

```text
expected_raw_PAD = intercept + slope * (A - age_center)
corrected_age    = P - expected_raw_PAD
raw_PAD          = P - A
corrected_PAD    = corrected_age - A
```

The intercept is in years; the slope is in years of brain-PAD per chronological-age year. The calibration age centre is **45.95447407728471 years**. The [coefficient CSV](resources/age_bias_correction.csv) preserves the original numerical precision and identifies every output explicitly. The accompanying [provenance JSON](resources/age_bias_correction.json) records the formula, validation sample summary and model, lookup and coefficient checksums. It contains aggregate calibration parameters, with no participant-level data.

This operation subtracts the expected validation-set age bias. **Corrected age depends on the supplied chronological age.** Evaluate predictive accuracy using raw predictions; corrected ages are derived measures for downstream analyses. Correction does not guarantee zero age dependence in a new cohort. The frozen calibration is specific to the bundled model and ROI definitions.

### Corrected outputs

| File | Contents |
| --- | --- |
| `corrected_predictions.csv` | Chronological age; raw and corrected direct-global and ROI-aggregated global ages; raw and corrected global brain-PAD; provenance fields. |
| `corrected_regional_predictions.csv` | Corrected regional ages in `roi_001` through `roi_222`, in years. |
| `corrected_regional_brain_pad.csv` | Corrected regional brain-PAD in `roi_001` through `roi_222`, in years. |
| `correction_metadata.json` | Source and output checksums, calibration/model/run identity, formula, sample counts, unused age records and extrapolation information. |

Global column names end in `_raw` or `_corrected`, for example `global_age_direct_corrected` and `global_pad_direct_corrected`. Missing regional predictions remain blank in both regional outputs. Positive brain-PAD means that the corresponding age estimate exceeds chronological age; negative brain-PAD means that it is lower. Correction does not change registration quality-control status or validate an otherwise unsuitable scan.

## Reproducibility checks

Run the correction tests without downloading MRI data or installing the inference dependencies:

```bash
python -m unittest discover -s tests -v
```

The tests cover the correction formula, ROI-specific coefficients, subject matching, missing ROIs, invalid inputs and preservation of raw files. Keep the software commit, environment, raw `run_metadata.json` and `correction_metadata.json` with each analysis. The pretrained model, atlas, template and original prediction calculations are unchanged by the optional correction workflow.
